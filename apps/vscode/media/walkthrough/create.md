# Create your first map

The quickest way to see a Wardley Map is to open the built-in example. Just click:

[Create map from example](command:wardley.newMapFromExample)

Want to start from a blank canvas instead? Click [Create empty map](command:wardley.newMap).

You can also run either command any time from the Command Palette
(`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux) by typing _"Wardley"_.

Either way you get a graphical editor backed by a plain-text file. Save it as `.wmap` or `.owm`
and that text file stays the source of truth, so Git, save, and diff all keep working.
